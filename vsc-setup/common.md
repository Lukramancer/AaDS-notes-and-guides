# Установка и настройка Visual Studio Code для дисциплины АиСД

Для решения лабораторных и лайв-кодингов необходимо написать код на одном из поддержиываемых платформой языков программирования. В силу особенностей каждого из языков, схожие решения на разных языках могут давать разную производительность и время исполнения, однако гарантируется, что все задачи возможно решить на C/C++.

Курс не ограничивает в выборе среды разработки. Здесь преведены руководства по устроновке и настройке Visual Studio Code - одной из рекомендованных менторами сред разработки:
- [Для Linux](./linux/guide.md) - проверено
- [Для Mac](./mac/guide.md) - теоретическое
